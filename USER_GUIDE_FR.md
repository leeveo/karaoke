# 🎤 PACKAGE KARAOKE - GUIDE UTILISATEUR FINAL

## ⚡ C'EST ULTRA SIMPLE MAINTENANT!

### Windows
1. **Télécharge le ZIP depuis l'admin**
2. **Extrait le dossier**
3. **Double-clique sur `start.bat`**
4. **C'est tout! Le reste se fait automatiquement! 🚀**

### Mac/Linux
1. **Télécharge le ZIP depuis l'admin**
2. **Extrait le dossier**
3. **Ouvre le terminal dans le dossier**
4. **Tape: `./start.sh`**
5. **C'est tout! Le reste se fait automatiquement! 🚀**

---

## 🎬 Que se passe-t-il quand tu cliques sur "start.bat"?

1. ✅ **Installation des dépendances** (première fois seulement, ~30-60 secondes)
2. ✅ **Démarrage du serveur** (quelques secondes)
3. ✅ **Ouverture automatique du navigateur**
4. ✅ **Tu arrives directement sur la page de ton événement**
5. 🎵 **Tu peux commencer à chanter!**

---

## 📥 Première utilisation - Téléchargement des chansons

La **première fois que tu utilises l'app**, elle doit télécharger toutes les chansons et images:

### Pendant le téléchargement:
- 📊 Une **barre de progression** s'affiche
- 🌍 Les fichiers se téléchargent depuis internet
- ⏱️ Temps estimé: 2-20 minutes (selon le nombre de chansons)

### Une fois terminé:
- ✅ Tout est stocké localement sur ton ordinateur
- 📵 **100% offline après ça!**
- ⚡ Le démarrage suivant sera ultra-rapide (5 secondes)

---

## 🎵 Une fois prêt - Que faire?

1. **Sélectionner une chanson** dans la liste
2. **Cliquer sur "Chanter"**
3. **Autoriser l'accès à la caméra** (popup)
4. **Chanter ta chanson!** 🎤
5. **Voir ton résultat**

---

## 🔧 Avant de commencer

Vérifie que tu as:

✅ **Node.js installé** (le package peut l'installer automatiquement)
✅ **Internet** (pour la première synchronisation)
✅ **Navigateur moderne** (Chrome, Firefox, Safari, Edge)
✅ **~500MB libre** (pour stocker les chansons)
✅ **Caméra/webcam** (pour les vidéos)

## ❓ Questions?

### "Ça met du temps à s'ouvrir"
- C'est normal! La **première fois** elle installe tout
- Les fois suivantes c'est plus rapide

### "Mon navigateur ne s'ouvre pas"
- Ouvre manuellement: `http://localhost:3000`
- Le terminal te le dira si ça ne marche pas

### "Les chansons ne se téléchargent pas"
- Vérifie ta connexion internet
- Attends un peu, ça peut être long selon la vitesse
- Regarde la barre de progression

### "Je veux arrêter l'app"
- Appuie sur **Ctrl+C** dans le terminal
- Ou ferme juste la fenêtre du terminal
